# Excel Merger (엑셀 병합 도구)

| Windows | Ubuntu |
| --- | --- |
| ![poster](./lib/windows.png) | ![poster](./lib/ubuntu.png) |

**Excel Merger**는 흩어져 있는 여러 개의 엑셀 파일(.xlsx, .xls, .xlsm, .xlsb, .csv 등)을 단 몇 번의 클릭만으로 하나의 파일로 깔끔하게 합쳐주는 크로스 플랫폼 데스크톱 프로그램입니다. Windows, macOS, Linux(Ubuntu)를 모두 지원합니다!

## 🌟 주요 기능

- **다양한 병합 방식 지원**
  - **시트별 병합**: 여러 파일의 시트들을 하나의 엑셀 파일 안에 여러 개의 시트로 모아줍니다.
  - **세로 병합 (위아래)**: 여러 파일의 데이터를 위아래로 길게 이어 붙입니다.
  - **가로 병합 (좌우)**: 여러 파일의 데이터를 좌우로 넓게 이어 붙입니다.
- **원본 서식 완벽 유지 (고품질 병합)**
  - 단순한 데이터뿐만 아니라 셀 색상, 수식, 병합된 셀, 열 너비 등 엑셀의 디자인과 서식을 그대로 보존합니다. 프로그램이 PC에 설치된 엑셀, 리브레오피스(LibreOffice) 등을 똑똑하게 자동 인식하여 최상의 결과물을 만들어냅니다.
- **매크로 파일(.xlsm) 보존**
  - 매크로가 포함된 엑셀 파일을 합칠 때, 매크로를 잃어버리지 않도록 자동으로 `.xlsm` 형식으로 저장해 줍니다.
- **암호 파일 완벽 지원**
  - 비밀번호가 걸려있는 엑셀 파일도 문제없이 불러올 수 있으며, 한 번 입력한 비밀번호는 PC 내부에 안전하게 암호화되어 저장되므로 매번 입력할 필요가 없습니다. 또한 최종 완성된 파일에도 암호를 걸어 안전하게 저장할 수 있습니다.
- **자동 업데이트 기능**
  - 새로운 버전이 출시되면 프로그램 시작 시 자동으로 알려주고, 버튼 한 번으로 최신 버전으로 손쉽게 업데이트할 수 있습니다.

## 📥 다운로드 및 실행 방법

1. [GitHub Releases (릴리즈 페이지)](https://github.com/Fentanest/ExcelMerger/releases/latest)에 접속합니다.
2. 사용 중인 운영체제(Windows, Mac, Ubuntu)에 맞는 파일을 다운로드합니다.
   - **💡 팁(Tip)**: 파일명에 `jre`가 포함된 버전(예: `...-jre-windows...`)을 다운로드하시면, 컴퓨터에 Java나 엑셀이 설치되어 있지 않아도 자체 고품질 엔진이 완벽하게 동작하므로 다운로드를 권장합니다.
3. 다운로드받은 프로그램을 실행합니다. 복잡한 설치 과정 없이 바로 사용할 수 있습니다!

## 💻 사용 방법 (단 3단계!)

1. **파일 추가하기**
   - 합치고 싶은 엑셀 파일들을 화면에 드래그 앤 드롭(끌어다 놓기) 하거나, `파일 추가` 버튼을 눌러 선택합니다.
2. **병합 옵션 선택하기**
   - **병합 방식**: 시트별로 나눌지, 위아래로 붙일지, 좌우로 붙일지 선택합니다.
   - **병합 엔진**: 기본값인 **'자동(권장)'**으로 두시면, 현재 컴퓨터 환경에서 가장 좋은 품질로 합칠 수 있는 방식을 프로그램이 알아서 똑똑하게 선택합니다. (Microsoft Excel이 설치되어 있다면 자동으로 이를 우선 활용합니다.)
3. **병합 시작**
   - 하단의 `병합하기` 버튼을 누르고 저장할 위치와 파일 이름을 지정하면 모든 작업이 끝납니다!

## ⚙️ (참고) 똑똑한 자동 병합 엔진

Excel Merger는 사용자의 컴퓨터 환경에 맞춰 다음 중 가장 좋은 엔진을 스스로 판단하여 동작합니다. 사용자는 신경 쓸 필요 없이 '자동'만 선택하시면 됩니다!
1. **Microsoft Excel 엔진**: 윈도우에 엑셀이 설치되어 있다면 엑셀을 직접 조종하여 가장 완벽하게 병합합니다.
2. **LibreOffice 엔진**: 엑셀이 없고 리브레오피스가 설치되어 있다면 이를 훌륭한 대안으로 활용합니다.
3. **고품질 내장 엔진 (JPype/Java)**: 엑셀이나 리브레오피스가 없어도 서식을 최대한 완벽하게 유지해 줍니다. (JRE 포함 버전을 다운로드하셨다면 항상 작동합니다.)
4. **표준 엔진**: 가장 기본적이고 가벼운 병합 방식입니다.

## 🔐 개인정보 보호 및 보안
Excel Merger는 병합 작업을 오직 사용자 PC 내부에서만 오프라인으로 안전하게 처리합니다. 소중한 업무 데이터나 문서가 외부 서버로 전송되지 않으니 안심하고 사용하세요! (인터넷은 새로운 버전이 있는지 업데이트를 확인할 때만 잠시 사용됩니다.)
